# AI Flow v1.1.0

本版本补齐“规划模型制定方案，执行模型接续开发”的项目内交接能力，支持跨编辑器沿用同一计划。

- 任务执行契约：保存接口、约束、代码入口、步骤、边界情况、必要测试和停止条件；检查计划输入是否过期。
- 分开提供简短用户进度和完整执行上下文；预算不足时要求拆任务或增大预算，不截断约束。
- 持久记录规划、执行、独立评审的角色；冲突带证据交回规划者，执行者不能自行通过评审或扩大运行预算。
- 工程扫描只输出候选；修复测试 fixtures 被误识别成项目技术栈的问题。确认事实带来源版本，替换旧结论需明确记录，来源变化后停止使用过期交接。
- 提供真实模型能力与成本评估方法及空白结果模板，不把流程回归测试当作 MiniMax/K2 实测。

兼容 v1.0 原有任务，升级保留进度和验收状态。跨模型接手前补齐执行契约、核实工程画像。当前发布包包含此前本地 v1.0 的验收归档与升级连续性改进。

验证覆盖 Go 回归测试、静态检查、安装/升级端到端场景和独立使用验证。最终命令结果与发布包校验和随本地发布记录保存。Windows 二进制可交叉编译，未声称在 Windows 原生执行安装测试。

限制：角色身份由宿主声明，工具不是身份认证或编辑器沙箱；未接入第三方模型调用，不承诺特定模型能力或节省比例。候选知识的语义核实和测试设计质量仍依赖规划与评审。无需清空聊天上下文。用户人工验收与远程发布各自保留真实状态。

回退：保存升级后新增记录，按升级备份映射恢复对应旧版记录并安装匹配版本。不要把不理解 v1.1 契约的旧工具直接用于写入新记录。
