# AI Flow v1.0.0

本版本把长期开发的当前计划、人工验收、过程归档和升级续接连起来。

- 进度默认简短汇报当前目标、进行中工作、验证状态和下一步。只采用当前有效计划；计划发布与实际发布分开。失效的生成页面归档，详细页面也检查是否过期。
- 测试绑定实际代码和未提交改动，同一检查展示最新可信结果。完成前必须有当前测试、评审、人工验证步骤和用户实际反馈；失败继续原任务，通过后归档过程材料，历史引用仍可查询。
- 计划汇报、独立调研、新功能、升级和验收反馈均有明确入口。独立调研停在适用性结论；小功能复用已有决策。查进度不会凭空增加用户选择。
- 升级先备份再转换，保留原任务和待确认事项。重新扫描项目、提取历史有效要求、修复引用并校验后，才能继续开发。支持中断续做和未完成迁移的资料恢复。
- 补齐任务依赖、保护路径、必需检查和风险字段；限制重叠写入；执行时间、重试和改动范围预算可检查并有明确调整记录。
- 安装器从包清单读取版本并验证运行时一致，防止安装标记与实际版本脱节。

这是工作流兼容性升级。已有项目请按[升级与恢复](upgrade.md)核对资料；旧测试记录不会自动获得新版验收资格，历史已完成任务保留原有事实，不伪造用户验收。

人工验收见[验证步骤](v1-acceptance.md)。此文件是发布说明源稿，不代表已创建标签或已对外发布。PowerShell 路径由 Windows CI 验证；本地 macOS 检查不能替代 Windows 实际运行。三种编辑器的模型触发依赖其读取已安装的入口规则，需要真实会话验收。

源码仓库自己的开发会话记录和生成看板保留在本地，不打入发行包；业务项目是否把项目记录加入 Git，由其自身约定决定。
