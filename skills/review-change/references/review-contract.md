# Review contract

Record:

- Review ID, reviewer/run identity, base and head Git SHAs.
- Linked Work Item, Requirements, decisions, tests, and evidence.
- Finding severity: `blocking`, `high`, `medium`, `low`, or `note`.
- For each finding: location, violated requirement/policy, concrete impact, and safe correction.
- Independent commands run and results.
- Final disposition and unresolved risks.

An empty finding list is not enough for approval; record which requirement, design, and evidence surfaces were inspected.
