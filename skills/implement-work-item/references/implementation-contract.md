# Implementation handoff contract

Record:

- Work Item ID and inspected Git SHA.
- Files added, changed, generated, and intentionally untouched.
- Acceptance criteria addressed by this increment.
- Focused commands and observed results.
- Any deviation from the accepted decision, with approval state.
- Known limitations, follow-ups, and migration concerns.
- Current checkpoint and next verification command.

Implementation status may be `in_progress` or `ready_for_verification`; only verification and review can make it releasable.
