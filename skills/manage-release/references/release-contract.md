# Release contract

Record:

- Release ID, previous version, proposed/actual version, status, and timestamp.
- Included Goals, Requirements, Work Items, commits, reviews, and evidence.
- User-visible additions, fixes, breaking changes, and removals.
- Migration and compatibility instructions.
- Known issues and explicitly deferred work.
- Rollback or safe-disable procedure.
- Tag, package, deployment, and remote release identifiers only after observation.

Default SemVer examples: major goal `v1.0.0`, compatible feature `v1.1.0`, fix `v1.1.1`.
