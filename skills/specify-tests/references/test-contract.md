# Test contract

Record for each test:

- Test ID and linked Requirement/Work Item.
- Test level and purpose.
- Preconditions, fixtures, and environment.
- Exact command or automation entry point.
- Expected result and meaningful failure signal.
- Pre-implementation result when applicable.
- Required evidence fields: timestamp, Git SHA, exit code, environment summary, and report/log hash.

The test plan must include acceptance behavior, expected errors, important boundaries, and regressions affected by the change.
