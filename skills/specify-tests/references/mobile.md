# Mobile tests

- Unit-test domain state transitions and view-model/reducer behavior without platform I/O where practical.
- Add component/widget/UI tests for rendering and interaction, then device/emulator E2E for critical journeys.
- Cover lifecycle, navigation, offline, permissions, localization, accessibility, orientation/window size, and supported OS/device risk.
- Use existing screenshot/golden tooling for stable UI states and require human/AI review for intentional design changes.
