# Decision contract

Record:

- Decision ID, status, scope, owner, and date.
- Linked Goal, Requirements, and Work Items.
- Context, constraints, and evaluation criteria.
- Options with evidence, strengths, weaknesses, project fit, risks, cost, and tradeoffs.
- Recommended option and the reason it best matches the user's priorities.
- UX/UI prototype paths and the uncertainty each prototype tests when visual exploration is used.
- User confirmation status, selected option, feedback, and confirmation time.
- Chosen design and implementation boundaries.
- Data/API compatibility and migration plan.
- Security, performance, operations, and test implications.
- Rollback or safe-disable path.
- Rejected alternatives and why.
- `supersedes`/`superseded_by` links when replacing a decision.
