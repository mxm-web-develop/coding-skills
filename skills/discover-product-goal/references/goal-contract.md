# Goal contract

Require:

- Stable Goal ID and proposed target release.
- Problem statement and desired outcome.
- Primary users or actors.
- In-scope capabilities.
- Explicit non-goals.
- Constraints and assumptions.
- Acceptance criteria observable by a user or system.
- Success measures when measurable.
- Risks, unresolved questions, and approval status.

Write requirements as independently verifiable statements. Avoid embedding a technical solution unless it is a confirmed constraint.
